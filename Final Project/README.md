## 🏠 Featured Project: House Price Prediction

The House Price Prediction project uses the California Housing dataset to predict district-level median house values using machine learning.

**Key components:**
- Dataset exploration and preprocessing
- Exploratory Data Analysis (EDA)
- Linear Regression and Random Forest model comparison
- Model evaluation using MAE, RMSE, and R²
- Interactive prediction interface built with Streamlit
- GitHub version control and deployment preparation

📁 **Project Documentation:** [House Price Prediction](./house-price-prediction/)

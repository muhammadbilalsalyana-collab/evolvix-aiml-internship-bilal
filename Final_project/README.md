House Price Prediction
End-to-End Machine Learning Application
Evolvix | AI/ML Internship Capstone — Weeks 5–6

An end-to-end machine learning project that estimates median housing values using California housing data. The solution combines data analysis, predictive modeling, model evaluation, and an interactive web application to demonstrate the practical deployment of machine learning.

Project Overview
Housing value estimation is a regression problem influenced by socioeconomic, demographic, and geographical factors. This project develops a machine learning solution that learns patterns from the California Housing dataset and generates predictions from user-provided inputs.

The trained model is integrated into a Streamlit web application, making the prediction workflow accessible through a simple, interactive interface.

Project Type: Supervised Machine Learning · Regression
Dataset: California Housing
Models: Linear Regression · Random Forest Regressor
Interface: Streamlit

Objectives
Analyze and prepare housing data for machine learning.

Methodology
The project follows a structured machine learning workflow:

Data Exploration — Examine dataset structure, feature distributions, and relationships.
Preprocessing — Prepare input features and divide the data into training and testing sets.
Model Development — Train Linear Regression and Random Forest regression models.
Performance Evaluation — Compare models using Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R².
Model Selection — Identify the preferred model based on evaluation results.
Application Development — Connect the saved model to a Streamlit interface.
Deployment & Testing — Deploy the application and verify the complete prediction workflow.

Model Evaluation
Model performance is assessed using three regression metrics:

MAE: Measures the average absolute prediction error.
RMSE: Penalizes larger prediction errors more strongly.
R² Score: Measures the model's explanatory performance relative to a mean-based baseline.

Limitations

Results depend on the training dataset, feature quality, and model performance.
The application is an educational prototype and is not a substitute for professional property valuation.
